# Project developer-mode anisotropy

`soil_anisotropy_values(ofes, upper=None, lower=None, *, developer_mode=False)`
keeps normal upper/lower maxima of 100/10 by default. An explicit true policy
from WEPPpy Ron removes only those maxima; finite values >=1 remain required.
The native layer does not resolve users, project state or environment settings.
Deploy with the paired WEPPpy caller; source ratios and depth classification are unchanged.

The WEPPpy DM-01 contract owns activation, clone and archive/restore policy.
